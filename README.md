# ⚽️ チームつながる

サッカーチームの保護者連絡を、LINEから卒業して1つにまとめるスマホ向けWebアプリ（PWA）。

## 機能

- 📅 **予定カレンダー** … 試合・練習を月カレンダー＋リストで表示
- ✋ **参加表明** … 試合ごとに 参加 / 未定 / 不参加 をワンタップ。人数集計と未回答者がひと目で分かる
- 🔑 **鍵当番表** … グランドの鍵当番。自分の次の当番をトップに大きく表示
- 📢 **お知らせ掲示板** … 大事な連絡をピン留め固定。LINEのように流れない
- 🚗 **配車・乗り合わせ** … 試合ごとに「車出せます」を募集、空席に乗車登録
- 👥 **メンバー名簿** … 名前・お子さん・背番号・連絡先
- 📲 **PWA** … ホーム画面に追加でアプリのように起動。オフラインでも開く

ログインは不要。**招待リンク or 招待コード + 名前** だけで参加できます（年配の保護者にもやさしい設計）。

---

## セットアップ（最初の1回だけ）

### 1. データベースを準備する

1. [Supabase ダッシュボード](https://supabase.com/dashboard) を開く
2. 対象プロジェクト → 左メニュー **SQL Editor** → **New query**
3. このリポジトリの [`supabase/schema.sql`](supabase/schema.sql) の中身を全部貼り付け
4. 右下の **Run** を押す（テーブルとセキュリティ設定が一括で作られます）

> すでに `.env` に接続情報（URL / publishable key）は設定済みです。
> 別のプロジェクトを使う場合は `.env` を書き換えてください。

### 2. ローカルで動かす

```bash
npm install      # 初回のみ
npm run dev      # http://localhost:5173 が開く
```

「新しいチームを作る」→ チーム名と自分の名前を入力 → 完成！
チーム画面の「招待リンクを共有」を他の保護者にLINEで送れば、みんな参加できます。

## 公開する（みんなが使えるようにする）

一番かんたんなのは **Vercel**（無料）です。

1. このフォルダを GitHub にプッシュ
2. [vercel.com](https://vercel.com) でリポジトリをインポート
3. 環境変数に下記を設定（Settings → Environment Variables）
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. Deploy

`vercel.json` でページ更新時のルーティングも対応済みです。
公開後のURLをホーム画面に追加すると、アプリアイコンから起動できます（iOS: 共有 → ホーム画面に追加）。

## 技術構成

- Vite + React + TypeScript
- Tailwind CSS v4（iOS風デザイン）
- Supabase（PostgreSQL / REST）
- vite-plugin-pwa（ホーム画面追加・オフライン対応）

## セキュリティについて（重要）

このアプリは手軽さを優先し、ログイン認証なしで **推測されにくい招待リンク** によってチームを共有する方式です。
小さな保護者グループの利用を想定しています。より厳密な権限管理（個人ごとのログイン・本人確認）が必要になったら、
Supabase Auth への移行で対応できます（その場合は `supabase/schema.sql` の RLS ポリシーを差し替え）。
